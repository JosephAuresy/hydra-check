# Advice inventory: every finding Hydra Check can produce

Generated by `node tests/make_advice_inventory.js` from the rules themselves (each rule is fired on a small fixture from `tests/advice_triggers.js`), so the titles, severities and texts below are the current ones.

How to read the columns:

- **Evidence**: how we know the finding is right and what the engine does. `measured here` = reproduced on a real engine in the injected-fault benchmark (`results/pilot_table.md`, the pilot case number is given) or in the precision audit; `read in the engine source`; `documented`; `community-reported` (not reproduced here).
- **Plain version**: whether a plain-language version existed before this change. For the rule findings the existing text (`detail`, `fix`) is technical; the characterization messages were already plain sentences but had no steps.
- **Advice now**: all of them have `plain`, `why`, `steps`, `verify` and `evidence` (`src/advice.js`). **Engine line** = a "what the engine itself said" line from the pilot table (case numbers).
